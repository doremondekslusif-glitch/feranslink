# FeransLink V1

Prototype Windows web UI untuk FeransLink.

## Menjalankan
Tidak membutuhkan server untuk preview dasar. Buka `index.html` di Microsoft Edge.

## Status
UI V1: dashboard, tambah perangkat, penyimpanan lokal Device ID, remote-control placeholder, Fit/Stop UI.

## Berikutnya
Android app, signaling server, WebRTC/relay, screen capture, remote input, lalu packaging menjadi aplikasi Windows.
